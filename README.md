# DriveVault for WooCommerce

Seamlessly attach and serve WooCommerce downloadable products directly from Google Drive with a modern React UI and high-performance secure streaming downloads.

## Features

- **Direct Google Drive Integration**: Authenticate via Google OAuth 2.0.
- **Modern React File Picker**: Search and select files directly from WooCommerce product screens.
- **High-Performance Chunked Streaming**: Secure memory-safe downloads with HTTP Range/Resume support.
- **Shared Drive Support**: Full support for Google Workspace Team / Shared Drives.
- **WooCommerce HPOS Compatible**: High-Performance Order Storage ready.
- **Transients Caching**: Fast folder traversal and storage quota overview with skeleton loading.

## Development

```bash
# Install dependencies
npm install

# Start development watcher
npm start

# Build production assets
npm run build

# Create production release zip
npm run build:prod
```
